# 📚 Smart Study Generator Agent

An AI-powered study assistant that helps students generate personalized study content using **IBM watsonx.ai, IBM Granite Models, LangFlow, and Retrieval-Augmented Generation (RAG).**

## 🎯 Project Overview

The Smart Study Generator Agent is designed to make studying easier by using AI to generate useful learning content from a provided knowledge base.

The system combines **Generative AI and RAG** to provide study assistance based on relevant information from the uploaded knowledge source.

## ✨ Key Features

* 🤖 AI-powered study assistance
* 📖 Knowledge-base based responses
* 🔍 Retrieval-Augmented Generation (RAG)
* 📝 Personalized study content generation
* 🧠 Uses IBM Granite Models
* 🔗 Built using LangFlow
* ☁️ Developed with IBM watsonx.ai

## 🛠️ Technologies Used

* IBM watsonx.ai
* IBM Granite Models
* LangFlow
* Retrieval-Augmented Generation (RAG)
* AI / Generative AI
